# Marketplace Backend

Backend system for a marketplace application built with Spring Boot.

---

## Tech Stack

* Java 17
* Spring Boot
* Spring Data JPA
* MySQL
* Maven

---

## Features

* User Authentication (Register / Login)
* Product Management
* Cart System
* Order System
